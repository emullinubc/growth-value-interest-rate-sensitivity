# Interest Rate Sensitivity of Growth and Value Equities

> **Status:** 🚧 In Progress Fall 2026

## Overview

This project investigates whether growth equities are more sensitive to changes in long-term interest rates than value equities in the United States.

The economic motivation is that changes in long-term interest rates affect the discounting of future cash flows. Because a greater proportion of the valuation of growth stocks tends to depend on cash flows expected further into the future, growth equities may be more sensitive to changes in discount rates than value equities.

## Research Question

**Are growth stocks more sensitive to changes in the 10-year U.S. Treasury yield than value stocks?**

## Data

The project will use monthly portfolio return data from the **Ken French Data Library**, with book-to-market sorted portfolios used to represent growth and value equities. Interest rate data will come from the **Federal Reserve Economic Data (FRED)** database.

## Methodology

The analysis will combine the equity return and Treasury yield datasets at the monthly level and use regression analysis to estimate the sensitivity of growth and value portfolio returns to changes in the 10-year Treasury yield.

Potential extensions include:

- Fama-French factor controls
- Value-minus-growth relative performance
- Short- versus long-term Treasury yields
- Different time periods and economic environments
